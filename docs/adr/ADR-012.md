# ADR-012 — Durable SQLite/RDF room recovery

Status: OPEN. The original unresolved ADR-004 storage placeholder is tracked here
because the user-supplied ADR-004 kit assigns that number to semantic UI. No
accepted ADR is renumbered. Historical ADR001–003 references to ADR004 storage
continue to mean this open decision, not acceptance of a database implementation.

The ADR004 private logical snapshot file supports scoped quit/reopen only. It
does not settle transactional SQLite/RDF recovery, migrations or power-cut safety.
A future implementation needs its own contracts, crash/durability tests and review.
