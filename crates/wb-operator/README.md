# wb-operator — ADR005 foundation (not accepted)

Typed asynchronous, powerless providers receive a bounded semantic candidate
projection. The offline fixture supports an explicit GBP mortgage grammar and
returns only strict suggestions. Recursive duplicate JSON keys, unknown fields,
non-scalar values and oversized replies are rejected before typed deserialization.
Registry discovery revalidates exact admitted UI packages; raw metadata and paths
are excluded from provider context. Host proposals carry canonical composition,
input/UI digests and fresh identities; approval is explicit and single-use.

**Incomplete trust boundary:** proposal application is experimental pending the
policy/provenance issues in `docs/implementation/adr-005/BLOCKERS.md`. Do not expose
it through production Qt or advertise OP acceptance. No executable Operator UI,
coordinator, durable handoff or hosted acceptance evidence exists yet.

Tests: `cargo test --locked -p wb-operator`. Integration tests require the real
accepted UI fixture, registry inspection binary and Python validation dependencies;
prepare those with the existing VSLICE002 validation workflow.
